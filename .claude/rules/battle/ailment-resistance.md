# 状態異常耐性

キャラクター・敵が持つ、状態異常(と即死)のかかりやすさ。属性耐性(`element-resistance.md`)とは別の値で、状態異常の**成功率**にだけ効く。

- **唯一の実装箇所**: `domain/battle/AilmentResistanceFormula.kt`(成功率の計算・値の範囲)
- **モデル**: `domain/model/AilmentResistances.kt`(値を持つだけ)・`AilmentResistanceType`(耐性の項目)
- **関連**: 成功判定の順は`status-ailments.md`の「付与」、精神系は`mental-ailments.md`、感染の伝染は`status-ailments.md`の「手番終了時の処理」

## 項目と値

- **項目**(`AilmentResistanceType`。この順で扱い・表示・保存する): 毒・火傷・凍傷・凍結・感染・流血・麻痺・感電・即死・石化・汚染・呪怨・睡眠・スキル封印・目眩・精神系 の16項目。
- **状態異常との対応**(`AilmentResistanceType.of`):
  - MPスキル封印・TPスキル封印 → どちらも「スキル封印」
  - 洗脳・発狂・魅了・恐怖・挑発 → どちらも「精神系」
  - 即死(`ActiveSkillEffect.InstantDeath`) → 「即死」
  - **スタン・烙印には耐性が無く**、常に成功率がそのまま(`of`が`null`)。
- **値**: 0〜100の整数、既定100。`Character.ailmentResistances`(キャラ編集で設定。`characters.json`にキーが無い旧データ・欠けた項目は100)と`Enemy.ailmentResistances`(ゴブリン・オークは全て100)に持ち、`BattleFieldPawn.ailmentResistances`で参照する。バフ・デバフで変える仕組みは無い。戦闘中に変わらないので持ち越しの対象でもない。

## 成功率への効き方

- **実際の成功率** = `floor(成功率 × 耐性 / 100)`。例: 成功率90・耐性20 → 18。耐性100なら変わらず、耐性0なら必ず0。
- 判定は今までどおり`rollSuccess`: 実際の成功率が100なら乱数を引かず、それ以外(0を含む)は`nextInt(100)`を1回引く。つまり成功率100×耐性100のときだけ引かない。
- 耐性を見るのは**効果を受ける個体**。属性耐性の反射で使用者に跳ね返った効果は、使用者の状態異常耐性で判定する。
- 失敗の扱い(命中扱い・TP条件・ナレーション)は今の失敗と同じ。
- **恐怖のスタン**(手番開始時の30%)には精神系耐性は効かない。耐性が効くのは、恐怖を「かけられる」ときの成功判定だけ。

## 感染の伝染

- 手番終了時の伝染は「`nextInt(100) < 30` → うつる先を`nextInt(候補数)`で抽選 → **うつる先の感染耐性で判定**」の順。
- 耐性の判定は`rollSuccess(耐性)`: 耐性100なら乱数を引かず伝染、それ以外は`nextInt(100) < 耐性`で伝染。
- 失敗したら伝染しない(抽選の引き直しはしない)。出来事(`TurnEndEvent`)も文も出さない。

## 画面

- **キャラ編集**: 「状態異常耐性」の区分に16項目の入力欄(「毒耐性」の形)。0〜100の数字以外の入力は弾いて状態を変えない。空欄は保存時に100。新規作成時はすべて「100」。
- **戦闘の詳細ポップアップ**: 属性耐性と同じく「毒 100」の形で16項目を表示する。
